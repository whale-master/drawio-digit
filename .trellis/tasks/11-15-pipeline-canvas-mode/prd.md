# 画布流水模式与逐级延迟编辑

## 目标

在 draw.io 画布上只用键盘按整拍绘制并命名方块，生成延后若干拍的下一级；鼠标提供等效操作。上游改动由用户显式向后同步，同时保留下游已有手改。现有 WaveDrom 用弹窗编辑源码；流水模式直接在画布操作。

## 需求与验收

| 编号 | 用户操作 | 可观察结果 |
| --- | --- | --- |
| R1 模式 | 按 F8 或从「视图 → 流水模式」进入或退出，空画布可直接画第一行。 | 默认模式沿用 draw.io 行为。仅切换模式不产生文件修改。退出、切页或打开对话框后不拦截原有快捷键。 |
| R2 周期 | 设置正整数 N，周期尺显示第 1…N 拍。 | N=8 时矩阵恰有 8 列、9 条竖虚线。方块延至第 10 拍自动扩至 10 列；手动缩短至已用范围之内时提示最小值。 |
| R3 方块 | 在网格按 R 创建并命名，Shift+方向键可先选多拍；鼠标用「矩形」单击或拖绘。支持移动、调整时长和删除。Esc 取消手势。 | 从第 2 拍左边界拖到第 4 拍右边界画出三拍方块。缩放或平移后仍整拍吸附。每块至少一拍，同一行不能重叠，非法落点有反馈。 |
| R4 派生 | 在当前行按 Enter 或点「＋ 下一级」，输入相对当前行的非负整数延迟，默认 1，Enter 确认。 | 新行紧接所选行，复制当前可见内容；连续派生 +2、+1 后，首块依次在第 1、3、4 拍。支持 0 拍，拒绝负数或小数。 |
| R5 延迟 | Home 或点标题选整行，Space 或点方块选单块。左右键移动一拍；拖标题或块可移动多拍。 | 移动行只改变该行起点；移动块只改变该块。后续行在显式同步前保持当前位置。 |
| R6 同步 | 选中起始行，按 Shift+Enter 或点「同步后续行」。逐级传播修改，保留本地新增、删除和改过的字段。 | 下方贯穿样例成立；重复执行不产生重复块。若冲突导致重叠，指出行及占用周期，整次同步保持原状态。 |
| R7 文件与撤销 | 绘制、拖动、生成下一级、全链同步各可一次撤销和重做。保存后重开仍可继续同步。 | 每次撤销同时恢复图面、派生关系、手改和列数。禁用插件仍可查看；SVG/PNG 导出包含周期尺和方块，不含编辑手柄。 |

## 贯穿样例

1. 第一级在第 1、2 拍画 A、B；第二级延迟 2 拍，第三级相对第二级再延迟 1 拍。此时 B 在第 2、4、5 拍。
2. 在第二级将 B 改名为 B′，在第一级第 3 拍新增 C。从第一级同步后，第二级为 A@3、B′@4、C@5，第三级为 A@4、B′@5、C@6。
3. 将第二级整体右移一拍。第三级仍从第 4 拍开始；从第二级同步后，第三级从第 5 拍开始。撤销同步，第三级回到第 4 拍，第二级的右移仍在。

## 全键盘绘制与方块名称（R8、R9）

R8 要求从已打开的空白编辑页开始，开启模式、定位、设置周期、绘制多拍方块、派生、同步和退出均可只用键盘完成。F8 切换模式，进入即聚焦第一级第 1 拍。周期数可用 Tab 到达工具条设置。网格光标显示当前行和拍号，移动到可视区外时画布自动跟随。

R9 要求新建方块时直接输入单行名称，已有方块按 F2 或双击改名。允许空名、重名、中文及标点。新建和首次命名合为一次撤销，单独改名可单独撤销。名称按稳定块 ID 继承，保存、重开及导出后保留。输入法确认候选不提交名称。

**无鼠标验收路径**

1. 按 F8 → R，输入“读取”，按 Tab 落块并开始下一拍。输入“计算”，按 Enter 落块，光标回到第 3 拍。要画多拍块，先用 Shift+←/→ 选定范围再按 R。
2. 网格中按 Enter，输入 2 后确认，生成第二级；再按 Enter 并接受默认延迟 1，生成第三级。每次派生后光标落在新行起始拍。
3. 按 ↑ 回第二级，在“计算”块上按 F2 改为“计算（备用）”。回第一级第 3 拍新建“写回”，按 Shift+Enter 同步。第二、三级的“写回”分别位于第 5、6 拍，“计算（备用）”在两级均可见。
4. 在第二级按 Home 选行、→ 延后一拍，再按 Shift+Enter 同步。用 Ctrl+Z 撤销同步，按 F8 退出并恢复宿主焦点。全程无需点击画布、按钮或输入框。

## 范围与评审取舍

面向本地网页版桌面键鼠操作，支持线性流水、整数周期、单行多个矩形和页面混排。分支汇合、资源调度仿真、半拍、逐块外部连线和跨页同步留待后续。

建议初始 8 拍。成品保留静态周期尺与细虚线，编辑时显示落点和工具；上游删除下游手改过的块时，建议将其保留为下游本地块。若在中间插入一级，原后继继续保持可见位置，按新上一级重算延迟；无法满足非负延迟时提示并取消插入。
