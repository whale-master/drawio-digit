# 实施顺序与验证

以 prd.md 的 R1–R9 和贯穿样例判断完成。以下为实施顺序，实际验证结果记录在文末。

1. **画布入口与交互验证（R1、R3）。** 在 src/pipeline/ 增加插件，通过 scripts/build.mjs 注册。打通切换动作、临时首行、编辑层焦点和退出回退。验证真实拖动与键盘优先级，在 50%、100%、200% 缩放和滚动后检查同一拍的命中位置。
2. **纯模型命令（R2–R6）。** 实现版本化记录、整拍布局、命令校验、快照及逐字段合并。模型测试覆盖零延迟、多拍、相邻区间、手改与上游删除、中间插行及负延迟拒绝、重复同步、发生冲突时整链回滚。用 PRD 样例断言可见拍号。
3. **图面与文件往返（R2、R7）。** 生成自包含 SVG，同一事务写属性、图像和几何。覆盖撤销重读、扩列、复制独立性、损坏/未知版本和禁用插件查看。检查缩放后的图元扩宽仍保持左上角和拍宽。
4. **键鼠命令（R1、R3–R6）。** 实现 R、点击/拖绘、标题选行、块重命名与拉伸、左右移动、Enter 派生以及 Shift+Enter 同步，提供等效鼠标动作。检查重叠反馈、取消、锁定、文本和输入法焦点、普通图形以及 WaveDrom 弹窗。
5. **回归与说明（R1–R9）。** 在 tests/ 增加流水模型和浏览器用例，更新 package.json 的测试入口，使新旧浏览器用例都运行。README.md 补充操作入口、快捷键和含手改的同步样例。

## 全键盘交付与回归（R8、R9）

1. 入口阶段先验证 F8 从宿主空白页开启、网格首格自动聚焦、可见光标和退出焦点还原。命令阶段实现按拍导航、键盘选区、R 新建命名、Tab 连录、F2 改名、键盘选行/块和调整时长。README 加入逐键样例。
2. 新增独立浏览器用例，仅通过 Playwright 键盘操作走完 PRD 的四步路径；不得使用 click、脚本 focus 或直接调用命令来代替用户输入。检查每次确认/取消后的焦点、块名、可见拍号及同步结果；保留鼠标拖绘的单独回归。
3. 补测三拍区间、空名和重名、Tab 遇已占用拍、末列后取消草稿不扩列，以及单独撤销改名。保存重开与 SVG/PNG 导出检查含中文和 & 的名称。使用真实中文输入法手动验证选词 Enter 和提交 Enter 独立；退出后复核宿主 F2 与 Shift+Enter。

## 验证命令与交付条件

- 新增模型测试后执行 `node --test tests/pipeline-model.test.cjs`。覆盖上游调整后的字段继承、相对延迟和已显示位置；校验失败时所有行与列数均恢复原值。
- 执行 `npm run build`；用 `npm start` 启动本地服务，另开终端运行 `npm run test:browser`。从真实菜单、键盘和鼠标走完三行样例；检查单次撤销/重做、下载重开后的再次同步、插件禁用查看、SVG/PNG 图面以及现有波形回归。
- 人工复核输入法组合、编辑中切页、只读/锁定、滚动后边界命中以及中文标签和 & 字符的导出。记录实际结果；目前的源码调查不代替浏览器验证。
- 主要回归面为构建脚本的插件列表、按键优先级、坐标换算和保存导出。若需停用，撤下新增插件注册，已保存的 SVG 仍可读取。
