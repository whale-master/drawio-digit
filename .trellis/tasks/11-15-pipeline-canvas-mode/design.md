# 流水模式技术设计

## 画布与文件

每张矩阵用一个 draw.io 图像图元保存自包含 SVG 和版本化的 pipelineData XML 属性。在图元实际占据的画布区域叠加可聚焦的编辑层，用于选择行/块、预览和拖动；无需打开对话框编辑整图。默认模式沿用图元的整体移动、等比缩放及外部连接，普通 draw.io 直接显示已保存的 SVG。独立插件放在 src/pipeline/；注册入口、可复用 API 和浏览器测试位置见 research/drawio.md。

开启时优先编辑当前选中的矩阵，否则定位本页最近编辑且仍存在的矩阵，再否则选本页首张。点另一张矩阵可切换。空页先显示临时第一行，仅首次有效绘制才写图元。模式、焦点、选区和拖动预览属于会话状态。切页、关闭文件和删除目标都取消临时手势；新页面从默认模式进入。损坏或未知版本保留已有图像并提示，锁定及只读状态禁止编辑。复制整图后内部关联键只在副本内解析。

## 数据与坐标

- 版本 1 保存周期数和有序行列表。行含稳定 ID、标题、已显示的起点、相对前一行的计划延迟，以及最近一次继承的块快照、本地新增、逐字段覆盖和隐藏标记。第一行直接保存其内容。块含稳定关联键、标签、起始偏移和时长。行顺序确定唯一上一级。
- 采用从 0 起算的整拍和左闭右开区间。显示起始拍号 = 行起点 + 块偏移 + 1。行起点与行内偏移均非负，时长至少 1；两个区间共用边界合法。移动行时从目标位置减去当前上级起点得到新延迟，拒绝负值。修改当前级时不重算其他行的已显示起点。
- 图元几何、周期尺、导出和命中测试共用一套布局。新列数取已设列数和全图最大结束位置的较大值；删除块后仅显式缩短才能收回空列。扩列或增行时锚定左上角，保持已有每拍显示宽度。特殊字符用 XML 属性 API 和 SVG 文本节点安全写入。

## 派生与同步

1. 派生以源行当前有效块（包括本地修改）为新行基线，复制关联键，行起点加上指定延迟。中间插入时，原后继的起点减去新行起点即为其新延迟；负值则整次取消。保留原后继已经落盘的快照与覆盖，待显式同步时合并。
2. 从选中行向下计算，每级新起点 = 本轮上一级新起点 + 本级计划延迟。以本轮上一级有效块替换目标继承快照，再叠加本行覆盖；改名只覆盖名称，未手改的长度、位置等仍继承。改回继承值时清除该字段的覆盖。结果用作下一级的输入。
3. 本地新增保留，已隐藏的继承块继续隐藏。上游删除的块若未在本行改过则移除；若手改过则取旧快照与覆盖合成最后可见内容，转换为本地块并保留关联键，保证其后代仍可匹配。已失去来源的隐藏标记可以清理。
4. 在内存中计算整条链，校验 ID、行内重叠、起点和时长。冲突返回行、方块和拍区间；所有后继状态一起保留供用户调整后重试。成功时用一次模型事务写入属性、图像和几何；无变化跳过写入。拖动中仅预览，撤销/重做从模型重新读取。

## 输入与生命周期

使用可切换的视图菜单动作和带键位提示的画布工具条。模式切换键可从宿主进入；其余流水命令仅在编辑层拥有焦点且目标可编辑时处理。重命名与延迟输入框自行处理 Enter 和 Esc；输入法组合、其他弹窗和普通图元按宿主行为处理。原生 Shift+Enter 已有绑定，首个实施步骤需要实测隔离焦点并阻止同一按键触发两次。

将指针转换到画布容器坐标，再按图元当前屏幕边界、行标题宽度和实际拍宽换算列。点选取所在列，落在内部边界归右列；拖边取最近周期线，反向绘制先归一化，合法的向右越界预览扩列。绕开宿主普通网格的二次吸附。缩放、平移、滚动和模型变化后刷新覆盖层；Esc、失去指针捕获或切页时清理监听和预览。静态周期尺、虚线和标签随 SVG 保存，浮动按钮、选区与拖动手柄仅出现在编辑层。

## 键盘命令与焦点

F8 为建议模式键。宿主编辑页没有活动弹窗、文本编辑或组合输入时可直接进入；同时提供 Tab 可达的菜单入口。进入时聚焦网格首格，退出恢复原焦点。可见光标由行 ID 与绝对拍号定位，与选区均为临时状态。周期数、矩阵选择和返回网格的控件均能通过 Tab 到达。

| 焦点 | 命令及其结果 |
| --- | --- |
| 网格 | ←/→ 逐拍；↑/↓ 换行保留列，必要时夹到该行起点。Shift+←/→ 以锚点扩展或收回范围；R 在空闲区间开始新块草稿，默认一拍，立即聚焦名称。F2 编辑光标所在块的原名。Enter 从当前行派生，Shift+Enter 从当前行同步。 |
| 已选对象 | Home 选当前行，Space 选光标处已有块。←/→ 移动所选对象一拍；选块时 Shift+←/→ 缩短或延长右边界一拍，Delete 删块。Esc 回到网格。对象选中时，派生与同步作用于所属行。 |
| 新块名称 | Enter 提交并回到块后第一拍。Tab 提交并在紧邻下一拍打开新草稿；若该拍已占用，停在网格且不覆盖原块。草稿可在末列之后临时显示，只有提交才扩列。Esc 取消当前草稿并回到起点。 |
| 已有块名称 | F2 或双击后选中旧名。Enter 提交，Esc 放弃，均将光标还给原块；失焦取消未提交内容。名称与稳定关联键独立。 |
| 延迟输入 | 默认值 1 已选中，可直接输入整数。Enter 确认并将网格焦点放在新行起点，Esc 回原行，输入无效时保留焦点并显示原因。 |

使用原生文本输入框处理名称。编辑时字符、方向键由输入框处理；组合输入期间，确认候选的按键不得透传为提交或派生命令。按键在当前状态只消费一次，随后才恢复焦点。区间非法时保留光标和选择并标明冲突拍。鼠标和键盘提交共用同一条“区间、名称、稳定 ID”创建命令与事务。

## 主要风险与降级

优先验证画布缩放、焦点及原生快捷键抢占。若宿主快捷键分发先消费事件，在可聚焦的编辑层入口处理并验证原生键回退；避免覆盖全局原型。插件被禁用后仍可依靠已存图像阅读和导出，恢复对应版本即可继续编辑。
