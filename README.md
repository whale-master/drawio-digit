# drawio-digit

基于 draw.io 的数字时序图编辑器，支持 WaveJSON 波形预览和全键盘绘制流水图。两种图都把可编辑数据与 SVG 一起保存到 `.drawio` 文件。

## 本地运行

需要 Node.js 20 或以上版本、npm、Python 3 和 Git。在仓库根目录运行：

```shell
git submodule update --init
npm ci
npm start
```

打开 [本地编辑器](http://127.0.0.1:8765/?lang=zh&ui=kennedy)。服务绑定到本机，按 Ctrl+C 结束。`npm run build` 单独生成 `dist/`，也可从此目录部署静态站点。

## 绘制和编辑波形

1. 点击工具栏的 **＋ → WaveDrom 波形图**。对话框会显示一份握手信号示例。
2. 把 `ready` 行的 `wave` 从 `'01..'` 改为 `'0.1.'`，可以看到上升沿推迟一拍。语法错误会显示在编辑框下方，上次有效预览会保留。
3. 点击 **应用**，再用 draw.io 的 **文件 → 保存** 保存为 `.drawio`。重新打开文件，双击波形即可继续编辑原始 WaveJSON。应用一次对应一次撤销。

普通 draw.io 可直接显示嵌入的波形图。在本项目的编辑器中打开同一个文件即可编辑源码。SVG 和 PNG 导出沿用 draw.io 的文件菜单。

## 在画布上绘制流水图

打开空白页，按 **F8** 或在「视图」菜单打开「流水模式」。默认显示 8 拍，方块超出右边界时自动扩列，工具栏可调整周期数。

1. 按 **R**，输入「读取」，按 **Tab** 接着在下一拍输入「计算」，再按 **Enter**。第一行现在有两个命名方块。名称支持中文、重名和留空。需要跨拍时，先按 **Shift+→** 扩展选择，再按 R。
2. 在网格按 **Enter**，输入 **2** 并确认，生成延后两拍的第二级。再按 Enter 并确认默认的 **1**，生成第三级。「读取」分别位于第 1、3、4 拍。
3. 用方向键定位到第二级的「计算」，按 **F2** 改名并确认。回第一级追加「写回」，按 **Shift+Enter** 同步后续行。第二级的手改名称会保留，并传给第三级。

| 操作 | 键盘 |
| --- | --- |
| 选择当前行并调整延迟 | Home，随后按 ← / → |
| 选择光标下的方块并移动 | 空格，随后按 ← / → |
| 调整已选方块时长 / 删除 | Shift+← / Shift+→，或 Delete |
| 取消输入或选择 / 退出模式 | Esc / F8 |

也可用工具栏、拖动和双击完成绘制与改名。保存后在本编辑器按 F8 可继续编辑；普通 draw.io 可直接阅读并导出保存的图面。

## 验证

运行 `npm test` 检查流水模型。本地服务启动后，在另一个终端运行 `npm run test:browser`。回归测试使用本机 Chrome；若使用 Edge，可将环境变量 `CHROME_CHANNEL` 设为 `msedge`。浏览器用例覆盖流水键鼠编辑、同步和现有波形功能，以及撤销、文件往返与图像导出。
