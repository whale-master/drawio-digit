# WaveDrom 集成规划

首版已在本地网页版实现。用户可以插入数字时序图，保存为普通 `.drawio` 文件，再次打开时双击继续编辑 WaveJSON。[本地运行与浏览器回归说明](../README.md)

## 源码基线

| 组件 | 当前固定版本 | 可复用的入口 |
|---|---|---|
| draw.io | 32.6.10，`c72c9a9` | [插件注册与菜单示例](../vendor/drawio/src/main/webapp/plugins/props.js)；[EditorUi.js](../vendor/drawio/src/main/webapp/js/diagramly/EditorUi.js) 中的 `createMermaidImageXml` 示范如何在同一图元中存储图像和源码。 |
| WaveDrom | 3.8.0，`5f44f7d` | [官方命令行入口](../vendor/wavedrom/bin/cli.js) 使用 `json5.parse`、`renderAny` 和 SVG 序列化；[信号渲染器](../vendor/wavedrom/lib/render-signal.js) 控制每张图的样式和图形定义。 |

## 首版编辑体验与文件格式

1. 用户选择“插入 → WaveDrom 波形图”，从一个时钟示例开始，或粘贴已有 WaveJSON。首版通过编辑 WaveJSON 源码修改信号，输入有效时旁边的预览自动刷新。单引号、未加引号的键和尾逗号均按 JSON5 解析。解析失败时显示错误位置，保留输入和上一次有效预览。
2. 应用后，在画布中创建一个可移动、缩放和连接的图像图元。图元携带内嵌 SVG，同时建议以独立属性 `wavedromData` 保存格式版本和原始源码，例如 `{version: 1, source: "..."}`。保存原文可保留注释、缩进和信号分组。
3. 双击波形图元恢复编辑框。只在确认后更新同一个图元，以一次 draw.io 事务写入源码与图像；保留位置、用户设置的尺寸和已有连线。取消或输入无效时，原图保持可用。普通 draw.io 可直接显示内嵌图像，加载扩展后可从原文重新编辑。

## 首版实施与验收

| 阶段 | 实施内容 | 通过条件 |
|---|---|---|
| 1. 本地渲染 | 在主仓库编写适配代码，从固定的 WaveDrom 子模块构建本地资源并随包附上 MIT 许可。沿用 CLI 的解析及渲染路径，对顶层 `signal` 输入做校验。将每幅图独立序列化，包含其使用的皮肤、样式和 `defs`。预览复用经过检查的 SVG 图像。 | 断开外网后，仍能显示 `p.......`、`P/N` 边沿标记、`{}` 空行和带中文标签的总线。将第二幅图单独打开时，其波形和样式完整。 |
| 2. 画布插入与编辑 | 用 `Draw.loadPlugin` 注册菜单动作。对带 `wavedromData` 的图元处理双击，按 draw.io 的图像数据 URI 和模型事务机制更新图元。开发服务器组合两个子模块与主仓库的插件产物。 | 同页插入两图，修改其中一图后，撤销、重做、复制粘贴均能保持源码和画面一致。打开其他类型图元时仍进入原编辑器。 |
| 3. 文件往返与导出 | 验证序列化、重复编辑、SVG 图像引用和导出。对缺少或版本未知的源码保留已有预览并给出提示。 | 保存并关闭文件，普通 draw.io 重开可见波形；带扩展的编辑器重开可恢复原文。导出 SVG、PNG 后检查箭头、总线文字和透明背景。 |

首版验收用 `clk / valid / ready / data` 握手图。在源码编辑框中把 `ready` 的 `wave` 从 `01..` 改成 `0.1.`，预览中的上升沿应推迟一拍。应用后检查撤销和重做，再保存并重开文件，确认双击能取回修改后的源码，导出图中也能看到对应的上升沿。

## 后续版本

图形编辑安排在首版之后。候选操作包括添加信号行、点选周期切换电平和拖动边沿。实施前先约定可精确回写的 WaveJSON 子集。验收时检查拖动一拍后波形与源码同步、撤销可恢复两者，以及未编辑的分组、节点和跨行标注能完整保留。

浏览器验证完成后，如需发布 Windows 桌面版，再把相同的渲染器和插件资源随定制桌面应用打包，并复测离线打开与导出。
